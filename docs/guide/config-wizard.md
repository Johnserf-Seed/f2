# F2 配置向导使用指南

## 简介

F2 配置向导是一个交互式工具，帮助用户快速生成 F2 的配置文件。它提供了类似于 `pnpm create`、`npm init` 或 `vue create` 的脚手架体验，让配置变得简单直观。

## 功能特点

- 🎯 **交互式配置**：通过简单的问答方式引导用户完成配置
- 🔧 **智能提示**：提供详细的字段说明和示例
- 📱 **多平台支持**：支持抖音、TikTok、微博、Twitter 等多个平台
- 🎨 **美观界面**：使用 Rich 库提供彩色、格式化的终端界面
- ✅ **配置验证**：在保存前预览并确认配置
- 📁 **灵活输出**：支持自定义配置文件保存路径
- 🎛️ **高级选项**：支持命名模板、日期区间、下载数量等高级配置
- 💬 **注释保留**：使用 ruamel.yaml 保留配置文件中的注释和格式
- 🔄 **智能默认值**：根据不同平台提供合理的默认配置选项

## 使用方法

### 基本用法

```bash
# 启动配置向导
f2 config-wizard
```

### 指定输出文件

```bash
# 指定配置文件保存路径，向导不再询问
f2 config-wizard -o my_custom_config.yaml
```

### 指定应用

```bash
# 只配置指定的应用（douyin、tiktok、weibo、twitter），跳过选择平台
f2 config-wizard -a douyin
```

## 配置流程

### 1. 欢迎界面

配置向导启动时会显示欢迎信息和功能介绍。

### 2. 选择平台

从支持的平台列表中选择要配置的应用：

- 抖音 (DouYin)
- TikTok
- 微博 (Weibo)
- Twitter (X)

可以选择多个平台，用逗号分隔，如：`1,2`

### 3. 配置参数

对于每个选择的平台，向导会引导您配置：

#### 必需参数
- **URL**: 目标链接
- **模式**: 下载模式（主页作品、点赞作品、直播等）
- **Cookie**: 身份验证信息（可选择稍后配置）

#### 可选参数
- **保存路径**: 下载文件的保存位置
- **文件命名**: 自定义文件命名模板
- **文件夹组织**: 是否按用户创建子文件夹
- **网络设置**: 超时时间、重试次数等
- **下载限制**: 最大下载数量控制
- **日期筛选**: 按日期区间过滤内容

### 4. 预览确认

配置完成后，向导会显示完整的配置预览，您可以：
- 确认配置并保存
- 取消并重新配置
- 修改保存路径

### 5. 保存配置

确认后，配置文件将保存到指定位置，向导会显示使用方法。

## 配置示例

### 抖音配置示例

```yaml
douyin:
  url: https://v.douyin.com/your-url-here
  mode: post
  path: Download/DouYin
  naming: "{create}_{desc}"
  folderize: true
  timeout: 10
  max_retries: 3
  max_counts: 100
  interval: "2025-01-01|2025-12-31"
```

### 多平台配置示例

```yaml
douyin:
  url: https://v.douyin.com/your-douyin-url
  mode: post
  path: Download/DouYin
  naming: "{create}_{desc}"
  interval: "all"

tiktok:
  url: https://www.tiktok.com/@username
  mode: like
  path: Download/TikTok
  naming: "{create_time}_{author}"
  max_counts: 50
```

## 使用生成的配置

配置文件生成后，可以这样使用：

```bash
# 使用配置文件
f2 dy -c your_config.yaml

# 或者对于多平台配置
f2 dy -c multi_platform_config.yaml
f2 tk -c multi_platform_config.yaml
```

## 高级功能

### 字段类型说明

- **str**: 字符串类型，如 URL、路径等
- **int**: 整数类型，如超时时间、重试次数等
- **bool**: 布尔类型，如是否创建文件夹等
- **choice**: 选择类型，如下载模式、命名模板等

### 高级配置选项

#### 命名模板
配置向导支持多种命名模板选项：
- `{create}_{desc}`: 创建时间_作品描述
- `{nickname}_{create}_{desc}`: 用户昵称_创建时间_作品描述
- `{aweme_id}_{desc}`: 作品ID_作品描述
- 自定义模板：支持用户自定义命名规则

#### 日期区间筛选
支持多种日期筛选方式：
- `all`: 下载所有作品（默认）
- `2025-01-01|2025-12-31`: 指定年份范围
- `recent_month`: 最近一个月
- `recent_week`: 最近一周
- 自定义区间：用户指定具体日期范围

#### 下载数量控制
可以设置最大下载数量：
- `0`: 不限制数量（默认）
- `10`, `50`, `100`, `500`: 常用数量选项
- 自定义数量：用户指定具体数量

### 默认值处理

配置向导会自动读取 F2 的默认配置模板，为各字段提供合适的默认值。

### 输入验证与错误处理

- **输入验证**：确保输入的值符合字段要求
- **空值处理**：对于空输入提供合理的默认值或提示重新输入
- **文件权限检查**：确保有权限写入指定路径
- **配置完整性验证**：确保必需字段都已配置
- **中断处理**：支持 Ctrl+C 安全退出配置过程

## 与现有配置系统的关系

配置向导生成的配置文件完全兼容 F2 现有的配置系统：

- 支持高低频参数分离
- 兼容 `--init-config` 和 `--update-config` 命令
- 可与手动编辑的配置文件混合使用
- 遵循现有的配置文件格式和约定
- 使用 ruamel.yaml 保留注释和格式
- 支持配置文件的增量更新

## 故障排除

### 常见问题

1. **命令找不到**
   ```bash
   # 确保使用正确的命令
   f2 config-wizard
   # 而不是 f2 config wizard
   ```

2. **权限错误**
   ```bash
   # 确保对输出目录有写权限
   f2 config-wizard -o ~/my_configs/f2.yaml
   ```

3. **配置文件无效**
   - 检查 YAML 格式是否正确
   - 确保必需字段都已填写

4. **中断处理错误**
   - 使用 Ctrl+C 可以安全退出配置过程
   - 如果遇到异常中断，重新启动向导即可

5. **空输入处理**
   - 大部分字段支持空输入使用默认值
   - 对于必需字段，会提示重新输入

### 获取帮助

```bash
# 查看配置向导帮助
f2 config-wizard --help

# 查看 F2 总体帮助
f2 --help
```

## 开发者说明

### 扩展应用支持

要添加新的应用支持，需要在 `ConfigWizard` 类的 `app_info` 字典中添加相应配置。

### 自定义字段

新的配置字段可以在 `field_descriptions` 字典中定义，包括类型、描述、默认值等。

### 本地化支持

配置向导支持国际化，所有用户可见的字符串都使用 `_()` 函数包装，便于翻译。
